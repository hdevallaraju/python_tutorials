# Strategy Dashboard (Web)

## Files
- `dashboard/index.html` — main page
- `dashboard/assets/styles.css` — styling
- `dashboard/assets/app.js` — tabs + last-updated date

## Open locally
Open `dashboard/index.html` in a browser (double-click).

## GitHub Pages (optional)
If you want this to be viewable as a webpage on GitHub Pages, place the contents under a `docs/` folder or enable Pages for the `dashboard/` folder depending on your repo settings.
